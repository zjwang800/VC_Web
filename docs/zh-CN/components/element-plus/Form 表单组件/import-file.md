## 属性

| 属性   | 说明            | 类型     | 可选值 | 默认值 |
| ------ | --------------- | -------- | ------ | ------ |
| name   | button 按钮名称 | string   | -      | -      |
| title  | 弹框名称        | string   | -      | -      |
| accept | 导入文件格式    | string   | -      | -      |
| import | 导入回调函数    | function | file   | file   |
